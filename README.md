# Energy

Energy exploration with data from **Our World in Data** (owid) and **SSB*. The data from owid are in the owid-energy.csv-file, along with 
explanation in the owid_energy.codebook.csv. This data is explored by country in the owid_energy.ipynb-file. The ssb data are fetched from 
the URL in the Electricity_exploring.ipynb-file.
